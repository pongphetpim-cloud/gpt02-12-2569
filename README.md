## แก้เนื้อหาแล้วสร้างใหม่

ทุกไฟล์สร้างจากสคริปต์ใน `_source/` — **แก้ที่สคริปต์ ไม่แก้ไฟล์ผลลัพธ์ตรง ๆ**

```bash
cd _source
PYTHONIOENCODING=utf-8 python build_slides.py      # slides.html
PYTHONIOENCODING=utf-8 python check_slides.py      # ตรวจสไลด์ล้น
PYTHONIOENCODING=utf-8 python build_workbook.py --pdf
PYTHONIOENCODING=utf-8 python build_card.py
PYTHONIOENCODING=utf-8 python build_prep.py
```

- prompt ทุกตัวอยู่ใน `_source/content.py` ที่เดียว → แก้ที่นี่แล้วรัน build สไลด์/คู่มือ/การ์ด ใหม่ทั้ง 3
- ไฟล์ตัวอย่าง: `gen_sales.py` → `gen_nb.py` (ต้องรันตามลำดับนี้) · `gen_text.py` · `gen_receipts.py` · `gen_e1.py` · `gen_readme.py`
- ห้ามใช้ `python -I` (หา `common.py` ไม่เจอ) · ไฟล์ .txt/.md/.csv ต้องมี UTF-8 BOM (`write_text()` ใส่ให้)
- ถ้าแก้ `assets/` ต้องทำ zip ใหม่และอัปทับใน Notion ด้วย (ชื่อไฟล์บน Notion ต้องเป็นภาษาอังกฤษ)
- ต้องมี Google Chrome (ใช้แปลง HTML เป็น PDF/PNG) และ Python + openpyxl, Pillow
